# Nexwall Firewall documentation

The administration guide of Nexwall Firewall, published at https://docs.nexwall.com.br.

The site is built with Docusaurus. Content is in `docs/`, organized like the menu of the web interface. Translations
are in `i18n/` (Portuguese for Brazil and Spanish).

Every change merged to `main` is built and published automatically. Pull requests get a preview.
