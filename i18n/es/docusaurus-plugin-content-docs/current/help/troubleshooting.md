# Solución de problemas: empiece aquí

¿Con prisa? Elija la línea que coincide con lo que ve. Cada KBA es corta, ordenada de la comprobación más rápida a la más profunda.

| Lo que ve | Vaya a |
|---|---|
| No sé por dónde empezar / después de un cambio | [KBA-01: Chequeo de salud en 5 minutos](kba-01-health-check.md) |
| No abre la interfaz web | [KBA-02](kba-02-web-interface.md) |
| La LAN no tiene internet | [KBA-03](kba-03-no-internet.md) |
| Un sitio o servicio publicado está bloqueado o inaccesible | [KBA-04](kba-04-site-unreachable.md) |
| Los nombres no resuelven | [KBA-05](kba-05-dns.md) |
| Una VPN no conecta | [KBA-06](kba-06-vpn.md) |
| El control de aplicaciones no hace nada | [KBA-07](kba-07-app-control.md) |
| Unidad lenta, poca memoria, servicios que se reinician | [KBA-08](kba-08-slow.md) |
| Los gráficos dicen que la base no responde | [KBA-09](kba-09-charts-db.md) |
| Fallan las actualizaciones | [KBA-10](kba-10-updates.md) |
| La unidad no se registra o no conecta al controlador | [KBA-11](controller-registration-troubleshooting.md) |
| Teams o Microsoft 365 no inicia sesión | [KBA-12](teams-microsoft-365-signin.md) |
| Windows muestra "sin internet" pero navega | [KBA-13](windows-offline-icon-sign-in.md) |

Los comandos, ubicaciones de archivos y contexto están en el grupo **Referencia** de la barra lateral.

## Cuando necesite pedir ayuda

Reúna, antes de contactar con el soporte: la versión de la unidad, lo que estaba haciendo, el mensaje exacto y las líneas
relevantes del registro. Si su plan lo incluye, abra una sesión de soporte remoto en **Administración > Licencias**.
