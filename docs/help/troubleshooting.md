# Troubleshooting: start here

Under pressure? Pick the line that matches what you see. Each KBA is short, ordered from the quickest check to the deepest one.

| What you see | Go to |
|---|---|
| I do not know where to start / after a change | [KBA-01: Health check in 5 minutes](kba-01-health-check.md) |
| Cannot open the web interface | [KBA-02](kba-02-web-interface.md) |
| LAN has no internet | [KBA-03](kba-03-no-internet.md) |
| One site or published service is blocked or unreachable | [KBA-04](kba-04-site-unreachable.md) |
| Names do not resolve | [KBA-05](kba-05-dns.md) |
| A VPN does not connect | [KBA-06](kba-06-vpn.md) |
| Application control does nothing | [KBA-07](kba-07-app-control.md) |
| Slow unit, low memory, services restarting | [KBA-08](kba-08-slow.md) |
| Charts say the database is unreachable | [KBA-09](kba-09-charts-db.md) |
| Updates fail | [KBA-10](kba-10-updates.md) |
| Unit will not register or connect to the controller | [KBA-11](controller-registration-troubleshooting.md) |
| Teams or Microsoft 365 will not sign in | [KBA-12](teams-microsoft-365-signin.md) |

Commands, file locations and background are in the **Reference** group of the sidebar.

## When you need to ask for help

Gather, before you contact support: the version of the unit, what you were doing, the exact message, and the relevant
lines of the log. If your plan includes it, open a remote support session from **Administration > Licensing**.
